# 抽血检查甲状腺功能时的注意事项

> 更新时间：2026-09-16 (UTC+8)

遇上甲状腺疾病这类慢性病，抽血要格外注意。今天就和大家唠唠**抽血查甲状腺功能的注意事项**。

1. 抽血前半个小时要保持安静状态，避免剧烈运动、情绪紧张。

2. 抽血前一天要规律作息，不要熬夜，尽量避免喝兴奋性的饮料（如酒、咖啡等）。

3. 在抽血前几天，避免食用富含碘的食物，比如海带、紫菜等，可能会影响甲状腺功能的评估。

4. 是否需要空腹呢？正常进食对甲状腺激素分泌影响不大，因此，检验甲功一般不需要空腹，但要注意避免过度进食，尤其是进食大量糖类食物，因为高糖饮食会刺激胰岛素抵抗，从而间接干扰甲状腺轴。但如果患者在查甲功的同时还要做其它需要空腹的检查项目（如肝功、血脂等），则须空腹抽血。

5. 如果正在服用某些影响甲功的药物，要提前的告知医生，比如说糖皮质激素、性激素、多巴胺、溴隐亭、胺碘酮、锂剂、苯妥英钠。

6. 如果您已经确诊了甲状腺疾病，比如甲亢、甲减、亚甲炎等，并且在接受药物的治疗，抽血的当天，应该正常服药，以客观反映药物的治疗效果，便于医生调整药量。

**那么，不同的甲状腺疾病，应多久去医院复查一次甲功呢？**

1. “甲亢”患者

口服药物治疗者，每4-6周复查一次；放射性碘治疗者，2-4周复查一次，如正常可改为每半年复查一次。

2. “甲减”患者

调整药物剂量期间，每月复查一次；用药剂量稳定后，每3～6个月复查一次。

3. “桥本甲状腺炎”患者

如果只是TPOAb和/或TgAb升高，不伴有甲减，1年左右复查一次甲功；如果伴有甲减，则参照甲减患者的复查频率检查。

4. 甲状腺癌术后患者

甲状腺癌患者术后需要口服左甲状腺素钠片，调整药物剂量期间，每月复查一次；用药剂量稳定后，根据医嘱定期复查。

5. 孕妇

甲减孕妇在孕20周以前，每4周检查一次甲功，孕20周以后每4-6周检查一次甲功直至分娩，产后6周复查一次；甲亢孕妇每2-6周检查一次甲功；单纯甲状腺自身抗体（TPOAb、TgAb）阳性而甲功正常的孕妇，妊娠前半期每4-6周检查一次甲功，妊娠26-32周期间至少检查一次甲功。

另外，需要提醒大家，即使您的指标正常，也需要定期复查。以免病情出现异常时没法儿察觉，如果病情稳定，3~6个月复查一次即可。
