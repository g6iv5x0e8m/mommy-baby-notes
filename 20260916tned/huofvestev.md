# 注意！抗菌药不是“万能药”，很多人都吃错了

> 更新时间：2026-09-16 (UTC+8)

人吃五谷杂粮

怎能不得病

生病后

大家最常见的治疗方式

就是服用药物

被视为**“万能药”**的**抗菌药物**

总在患者的首选药品名单之列

那么**正确使用抗菌药物**

**应该注意哪些问题呢**

**01**

**详细了解过敏史******

****

**了解自身及家人药物过敏的情况**********

详细了解患者**既往用药是否出现过敏情况以及家族中其他人使用抗菌药物的过敏情况**，避免再次使用曾经出现过不良反应的药品。

**严格执行皮试常规******

青霉素类药物的说明书和《中华人民共和国药典临床用药须知》都要求，使用青霉素类药前均须做**青霉素皮肤试验，阳性反应者禁用**。

**仔细阅读药物说明书******

我们在购买抗菌药物的时候，一定要**仔细阅读药物说明书**，特别要注意**药物的禁忌、注意事项、不良反应及药物间的相互作用等事项**，如有疑问，也要及时咨询药师或医生，切不可随意使用。

**02**

**特殊人群慎用**

****

****

对**儿童、老人、孕妇及肝肾功能不良**的特殊患者人群来说，在服用抗菌药物时有各自不同的**注意事项**。

例如：**老人**随着年龄的增长，肝肾等重要脏器的功能减退，使抗菌药物代谢减慢，在体内停留的时间延长，因此，**用药剂量和用药的间隔时间要根据个体情况来调节。**

随着机体合成功能的减退，老年人体内维生素合成较前减少，此时如果长期应用抗菌药物会进一步抑制维生素的合成，引发口腔溃疡、舌炎等；

而且老年患者服用药物种类多，有时会对抗菌药物的疗效、代谢产生影响。

这时**应仔细阅读说明书或寻求医师、药师的帮助，以避免不良反应的发生或诱发原有的疾病**。

**03**

**注意特殊药物用法**

****

**头孢曲松钠**

**头孢曲松严禁与任何含钙溶液同时使用**。

因合用后会发生化学反应，产生颗粒状的沉淀物，如通过静脉输注进入血管，会因堵住一些细小血管，发生严重的不良反应。

**红霉素**

由于在酸性条件下不易吸收，且在胃肠道中容易被破坏，因此**红霉素应避免与维生素C、阿司匹林等酸性药物合用**；

而**与碱性食物或药物同服时，需警惕因排出减慢，药效增强而导致副作用增强****。**

****

**04**

**注意食物和药物的影响**

**食物的影响**

**药物与食物结合后不能被吸收。**如喹诺酮类（左氧氟沙星、莫西沙星）、四环素类（四环素、多西环素）与含铁或钙的食物同服会形成复杂的难溶物质，从而降低药物的生物利用度。

**使用含甲硫四氮唑基团的头孢类抗菌药物**（头孢哌酮、头孢曲松、头孢唑林等）**严禁饮酒**，在使用**上述抗菌药期间及停药后7天内，均应避免饮酒或进食含酒精制品**（黄酒、啤酒、酒芯巧克力、藿香正气水等）。同时应避免用酒精进行皮肤消毒或擦洗降温，尤其老年人、心血管疾病患者更应注意。饮酒后48小时内（酒精代谢慢的患者需要间隔更长的时间）也应避免服用上述抗菌药物。

**药物的影响**

某些抗菌药物如红霉素、克拉霉素、伊曲康唑为肝药酶CYP3A4的强抑制剂，使洛伐他汀、辛伐他汀、阿托伐他汀代谢受阻，血药浓度升高，增加横纹肌溶解，肝、肾功能异常等不良反应的发生的风险。

**抗菌药物可不是“药神”**

**合适的时机选用合适的抗菌药**

**才是自我保护的有力盾牌**
